# Advanced Web Development — Course Catalog

A course catalog web application built with Next.js 16, TypeScript, Tailwind CSS, and the App Router.

## Implemented

- Home page (`/`)
- About page (`/about`)
- Course list (`/courses`)
- Dynamic course pages (`/courses/[id]`)
- Mock course data with `getCourses()` and `getCourse()`
- Dynamic routes with `generateStaticParams()`
- Loading UI with `loading.tsx`
- Custom not-found page
- `CourseCard` Server Component
- Interactive `LikeButton` Client Component using `useState`
- Shared navigation using Next.js `Link`
